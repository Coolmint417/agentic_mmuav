1105 改动：
现在，API 每次主要依据本次请求里的 messages 理解上下文；历史由本地 runner 维护并重新发送。

例如，一次“起飞后向前飞”的任务，消息列表会逐渐变成：
第一次请求
  system：系统提示词
  user：任务 + 初始观测 + 当前图片

第二次请求
  system：系统提示词
  user：任务 + 初始观测文字 + 初始观测图片
  assistant：{"tool":"takeoff"}
  user：任务 + 起飞结果 + 新观测 + 工具调用过程中的采样帧 + 当前图片

第三次请求
  system：系统提示词
  user：任务 + 初始观测文字
  assistant：{"tool":"takeoff"}
  user：任务 + 起飞结果 + 观测文字 + 起飞结束观测图片 (删除掉采样帧)
  assistant：{"tool":"fly_waypoint","waypoint":[...]}
  user：任务 + 飞行结果 + 新观测 + 工具调用过程中的采样帧 + 当前图片


1106 改动：
新增 aggressive_perch 工具，仅悬停可调用。输入单个表面接触点、yaw（rad）、平面倾角（30～90°）
和轨迹时间，开启四吸盘后用 minimum-snap 规划；末端 a=12n+gravity、v=-0.4n。
补充 jerk 边界约束、SE3 大俯仰姿态构造及专用轨迹跟踪，实际稳定四吸盘接触后停桨并进入 ON_GROUND，吸盘开关独立保存。
失败、超时及取消清理本次吸附并恢复原控制参数，工具后继续沿用过程观测与历史关键帧机制。


1106 吸盘状态重构：
移除 ADHERED 运动状态。FlightStateMachine 新增独立四元 sucker_states，按左前、左后、右后、右前
记录 adhesion 开启命令；任何运动状态及控制权模式都可修改。所有工具与遥控器动作统一写入，
环境同步四路驱动和摩擦。crawl 结束、perch 确认吸附后均进入 ON_GROUND（含墙面支撑），
吸盘开关保持各自设置，当前/过程观测及 UI 显示该四元向量。


1106 快速 perching 规划：
将末端 specific_thrust 从固定12改为有界优化变量（默认8～20 m/s²），与多项式系数共同最小化snap。
提示词强调距墙至少2m、1.5～1.8s快速接近；工具限制0<time<=2s，并校验平均法向接近速度>=1m/s。
终端触壁速度保留0.4m/s。仅优化推力和缩短时间仍不能完全阻止低空轨迹下沉，故增加Z>=0.25m约束，
以多项式导数根检查采样间极值，必要时补充约束重求解；工具结果增加planning诊断字段。
复测原日志两处起点、1.5/1.8/2s六组真实MuJoCo工况均吸附成功，详见artifacts诊断目录。
