# 独立日志重放

```bash
conda activate mm_planner
python replay_app.py logs/agent_log_11091541_agperch.jsonl --map map1
```

也可不传日志路径，启动后选择 JSONL。该入口使用独立的 PySide6 界面，无需模型权重、API Key 或模型后端连接，原 `app.py` 界面保持原样。依赖沿用现有 mm_planner 环境。

选择**原实验对应的地图**，点击“重置地图并开始”。每次开始均重新加载所选地图，从标准初始状态播放全部轮次。无需逐轮输入任务。日志文件不会被修改。

## 播放与暂停

- 跳过原模型思考和用户输入等待；不按日志墙钟时间等待。
- 事件展示间隔默认 0.3 s，可设为 0；这只是阅读节奏，不改变物理步长或工具控制周期。
- 只有 `tool_call` 调用 `runtime.execute_tool()`。`model_output`、`decision` 只展示，不重复触发工具；非法 JSON 和格式修正也按原记录展示。
- 工具使用本次仿真中的实际状态重新规划和执行，完成后采集新观测。工具耗时取决于本次执行，不强制对齐旧日志的耗时。
- “暂停”停止推进日志事件。若工具正在执行，显示待暂停，等工具执行及结果观测完成后才暂停。“继续”从下一条事件接着播放。
- 暂停期间 MuJoCo 正常步进，控制器、重力、接触与吸附继续运行，可能产生漂移。暂停不会保存或恢复物理状态。
- “终止”立即发起已有工具取消流程，不等待工具正常完成。关闭窗口也会终止并释放仿真资源。
- 仍遵守 Axis4 控制权；未检测到手柄时自动授权。撤销授权将终止重放。

## 界面内容

左侧为**本次重新渲染**的第一视角、世界视角或深度图。世界视角支持原有鼠标旋转、平移、滚轮缩放、Ctrl+滚轮改变 FOV、双击复位。

右侧包含：

- 原对话与输出：原用户任务、模型回复、已记录的推理内容、工具调用和格式错误。
- 原始 JSON：按顺序展示全部原始记录，包括模型完整 messages 输入和输出；来源日志的 timestamp、turn_id 保持原样。
- 本次执行对比：并排字段记录原工具结果与新工具结果，并比较各次观测的位置、状态和仿真时间。日志轮次 ID 与本次 runtime 轮次 ID 独立。

原工具返回失败时仍按日志继续执行后续决策；本次失败也不调用模型重新决策。运行异常、无授权或不兼容的工具协议会停止重放并显示错误。截断日志若停在工具之后，会在已完成的观测后结束本轮；不会虚构缺失的模型输出。

## 可恢复范围

现有 JSONL 记录的是决策和观测摘要，并没有保存原始 RGB/深度图片。`encoding: attachment` 只标识附件，不能从旧日志恢复模型当时看到的图像。界面的新画面不代表原输入图像。

旧日志通常也没有初始地图标识、完整关节状态、控制器内部状态、当时 XML/代码版本、模型思考期间的逐步物理状态。因此这是**相同决策的重新执行**，不保证原轨迹、接触、成功率或像素完全相同。使用对应的地图与代码版本、避免长时间暂停有助于减少偏差；真实差异以执行对比页为准。

## 代码入口

`agent/replay.py` 校验 JSONL，保留源事件；`agent/replay_runner.py` 在独立调度线程执行播放和暂停边界；`ui/replay_window.py` 负责显示；`replay_app.py` 启动应用。物理步进、工具、两个状态机及渲染仍由已有 `EnvironmentRuntime` 管理。
